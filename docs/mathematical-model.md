# ICR-OPT: Dynamic Geospatial and Techno-Economic Intra-Circle Roaming Model

**Research and implementation specification, v1.0**  
**Date:** 8 October 2026  
**Application:** Permanent or regularly available capacity-aware intra-circle roaming in selected Indian border and remote regions.  
**Status:** Exploratory planning model using synthetic input data. Not a measurement of any real TSP network, regulatory compliance certificate, or operational RAN controller.

## Executive formulation

Given a region divided into cells, four home network operators, and time-varying loads, identify (a) the physical coverage complementarity, (b) feasible guest-to-host traffic allocations, (c) the economically efficient subset of these allocations, (d) inter-operator settlement arrangements that make participation acceptable, and (e) regions that remain physically or economically unserved.

**Architecture**: geospatial incidence tensor -> directed coverage complementarity -> temporal residual network capacity -> multi-commodity-like traffic assignment -> settlement and cooperative bargaining -> scenario comparison -> optional infrastructure expansion.

The independent grid-cell approximation in the working simulator is an intentional proof-of-concept simplification. For operational decisions, replace it with a site/cell-sector resource model with shared tower/backhaul constraints and historical measured traffic.

## 1. Sets, parameters and units

- `G={1,...,N}`: spatial cells. For equal grids, each cell has equal area `a_g`; otherwise use unequal geospatial cell area.
- `I={1,...,M}`: operators, M=4 in prototype; indices `i` for home/guest and `j` for visited/host.
- `T={1,...,H}`: representative time slices, with `w_t` hours represented per slice (working prototype uses six four-hour windows).
- `S`: physical sites, sectors or logical radio resource pools in a production system.
- `c_gj in {0,1}`: host `j` has adequate service coverage in cell `g`, after radio threshold and technology validation.
- `e_gij in {0,1}`: technical, contractual and policy eligibility, requiring `i != j`, `c_gi=0`, `c_gj=1`; can also limit the eligible border area.
- `p_g`: resident/visitor demand intensity or population weight for cell `g`.
- `m_i`: operator subscriber share, summing to one.
- `d_git >= 0`: home `i`'s potentially recoverable roaming demand in `g,t` when own network unavailable, expressed in traffic-equivalent units per representative hour.
- `K_gjt >= 0`: gross host radio or service capacity before QoS protection, same throughput-equivalent units per hour.
- `L_gjt >= 0`: load generated by host's native users.
- `r_j in [0,1)`: fraction of gross capacity protected as an explicit QoS headroom reserve.
- `S_gjt=max(0,K_gjt*(1-r_j)-L_gjt)`: residual safe ICR capacity.
- `b_i`: incremental private value per traffic unit received by operator i's previously unserved subscriber, e.g. contribution margin, avoided churn, service value attributable to serving that volume; do not equate this mechanically to retail tariff.
- `q_git`: incremental social/public value per unit, distinct from private value. Use verified willingness-to-pay or policy weights when available.
- `c_j`: variable incremental host cost per unit.
- `gamma_j`: host congestion cost coefficient.
- `P_ij,t`: commercial inter-operator payment from guest i to host j per carried unit (the demonstrator uses host-specific P_j and an adjustable global multiplier).
- `F_i`: contract/fixed integration cost borne by operator i, excluded from v1 computations because it requires annualization and explicit deployment assumptions.
- `h_g in {0,1}`: eligibility of geographic cell g under border zone policy, optional.

**Units note:** The prototype uses artificial traffic-equivalent units per representative hour and synthetic INR per traffic-equivalent unit; it is not using GB, Erlangs or real tariff data. To convert to real units, separately model voice bearer/resource use, VoLTE/IMS registration, packet data usage, PRB utilization, backhaul constraints, session admission and handset capability.

## 2. Directed spatial complementarity

For each operator:

`C_i = (sum_g a_g*c_gi)/(sum_g a_g)` : its own area coverage.

`U_i = {g in G: c_gi = 0}` : its uncovered cells.

The directional complementarity (row i, column j), conditional on i having no native signal:

`M_ij = [sum_g a_g*(1-c_gi)*c_gj] / [sum_g a_g*(1-c_gi)]`, for i!=j and a nonzero denominator.

Thus M_ij differs from M_ji. **Entries in one row are not disjoint**. A cell may be covered by T2 and T3, so sums across host columns overstate recoverable geographic coverage.

For arbitrary host coalition `J subset I\{i}`:

`M_i(J) = sum_g a_g*(1-c_gi)*1{sum_{j in J}c_gj>=1} / sum_g a_g*(1-c_gi)`.

Unreachable fraction of i's gap is `1-M_i(I\{i})`.

**Exact example**. With 2,000 equal-area grids and T1 coverage 95%, exactly 100 cells are in T1's gap. If T2 covers 90 of those, T3 covers two different ones, and T4 covers zero, then the conditional row is `M_12=90%`, `M_13=2%`, `M_14=0%`, and 8% of T1's gap is unreachable under ICR. The simulator contains this exact constructed case. If T2/T3 overlapped, unreachable area would be at least 8%, not necessarily exactly 8%.

## 3. Residual capacity and protected QoS

At each cell/host/time, the prototype uses:

`S_gjt = max(0, K_j *(1-r) - K_j*u_j*ell_t * f_g) * c_gj`.

Here `u_j` is normal-time native utilization, `ell_t` is the synthetic temporal load multiplier, and `f_g` is a bounded synthetic population/demand density adjustment. All resources are expressed as equivalent traffic capacity.

The full model should index real radio serving sites `s` and backhaul links `l` and enforce:

`sum_{g,i} a_sgit * x_gijt <= S_sjt`, for every site-sector `s,j,t`.

`sum_{g,i,j} h_lgijt * x_gijt <= B_lt`, for every transport link `l,t`.

Also require roaming service eligibility (4G/VoLTE/5G support), network selection/PLMN agreements, emergency call routing, core-network authorization, authentication and the appropriate legal and security conditions.

The demonstrator **does not** implement these coupled constraints, inter-cell interference, stochastic handover failures, or measured QoS metrics. Headroom is a proxy, not a formal proof of meeting TRAI benchmarks.

## 4. Traffic assignment optimization

Decision `x_gijt >= 0` is the unit/hour home `i`'s previously uncovered subscribers route through visited operator `j` in geographic cell `g`, time `t`.

Constraints:

1. `x_gijt = 0` if `e_gij = 0`, including when own coverage exists or host coverage does not.
2. `sum_{j != i} x_gijt <= d_git` for each home/group `g,i,t`.
3. `sum_{i != j} x_gijt <= S_gjt` for each host capacity `g,j,t`.
4. `x_gijt >= 0`. Optional admission/protocol and coverage access constraints can further restrict flows.

Host incremental variable and congestion cost is convex:

`Phi_gjt(y) = c_j*y + (gamma_j/(2*S_gjt))*y^2` if S>0, where `y=sum_i x_gijt`.

`Phi(0)=0`; no traffic is admitted when `S=0`.

For pure incremental commercial efficiency:

`max_x sum_{g,i,j,t} w_t * b_i*x_gijt - sum_{g,j,t} w_t*Phi_gjt(sum_i x_gijt)`.

For social planning include distinct public value:

`max_x sum_{g,i,j,t} w_t * (b_i + q_git)*x_gijt - sum_{g,j,t} w_t*Phi_gjt(sum_i x_gijt)`.

Subject to the above capacity, demand and eligibility constraints. Payments `P*x` cancel in **aggregate welfare**, so they should not be inserted as new social costs. They instead determine distribution of operator gains and participation incentives.

### Solution method in prototype

The convex hosting cost `Phi` is approximated by four equally sized increasing marginal-cost segments. Each grid/time optimization is encoded as a min-cost flow graph:

- source -> home demand nodes, capacity `d_git`;
- home demand -> eligible host nodes, marginal cost `-(b_i+q_git)`;
- host nodes -> sink, four capacity segments, costs `c_j+gamma_j*(k+0.5)/4` for k=0..3.

Repeated shortest residual paths are augmented **only if they have strictly negative incremental cost**, so no traffic is routed when doing so would reduce the selected objective. Reverse residual edges permit flow reallocation. This is an exact min-cost flow solve for the four-segment linearized problem, not an exact optimizer for the original smooth quadratic objective. Reported costs use the original smooth convex formula evaluated at allocated traffic.

Because the present capacity model is independent across cells and representative periods, this decomposition is valid. Site/backhaul coupling would require a *global* min-cost flow formulation, MILP, convex optimization or a decomposition algorithm such as ADMM/column generation.

### Selective or bilateral ICR agreements

The implementation accepts a binary, **directed** permission matrix `A_ij`. All-to-all, T1-only guest access, strictly reciprocal T1/T2 agreements and individually editable pairwise access can be compared. An assignment is allowed only when `A_ij=1`. The raw coverage matrix is deliberately unaffected by commercial permissions, but the union of **eligible** hosts and all feasible traffic is recomputed when pairwise permissions change.

### Calculated bilateral wholesale tariff corridors

In addition to testing user-entered posted prices, the prototype estimates a pairwise bargaining corridor after solving the traffic allocation. Because host `j` may carry traffic for several guests in the same cell and interval, allocate the full incremental host cost proportionally to flows at that time:

`C_ij = sum_{g,t: Y_gjt>0} w_t * Phi_gjt(Y_gjt) * x_gijt/Y_gjt`, where `Y_gjt=sum_h x_ghjt`.

This satisfies `sum_i C_ij = H_j` exactly to floating-point precision. For total directional traffic `Q_ij = sum_g,t w_t*x_gijt`, define the average host cost allocation `h_ij=C_ij/Q_ij` (if Q>0). A **standalone indicative** mutually acceptable unit tariff corridor is:

`h_ij <= P_ij <= b_i`.

When the corridor is nonempty, its midpoint `P_ij^mid=(h_ij+b_i)/2` allocates this model's pair-specific operating surplus equally per traffic unit. When it is empty, pure bilateral unit pricing does not make that pair individually attractive at those assumptions. Cross-subsidy, multilateral clearing, public support or withdrawing some traffic may still resolve the overall arrangement. The implemented *posted* price used for traffic screening is a host-specific `P_j` multiplied by an adjustable scaling factor. Calculated `P_ij^mid` values are **diagnostic suggestions**, not automatically applied as host tariff inputs.

### Tariff-driven mode

For each guest-host edge, admission is permitted only if `b_i >= P_j`. On the host side, any congestion segment with `marginal cost > P_j` is unavailable. This models a simple posted-price, individual-incentive screen. It is not a full Bayesian market equilibrium, bargaining outcome, interconnect contract or strategic pricing game.

## 5. Private operator accounting and settlements

After allocation, define:

`B_i = sum_{g,j,t} w_t * b_i*x_gijt` : incremental value to home i.

`H_i = sum_{g,t} w_t*Phi_git(sum_{h!=i} x_ghit)` : cost of hosting other operators' roaming traffic on i.

`R_i = sum_{g,h,t} w_t*P_i*x_ghit` : roaming revenues received by i as visited network.

`Q_i = sum_{g,j,t} w_t*P_j*x_gijt` : roaming payments made by i as home network.

`Delta_i^posted = B_i-H_i+R_i-Q_i-F_i`.

With F_i=0 in prototype, `sum_i Delta_i^posted = sum_i B_i-sum_i H_i = S_private` because inter-operator payments net to zero. *The zero-sum character of transfers must not be confused with zero net welfare.*

### When can all operators benefit?

Without third-party subsidies, it is mathematically necessary that the privately realizable surplus of a **connected group of trading operators** be nonnegative. Positive aggregate surplus across unrelated network components does not by itself allow transfer between disconnected groups if settlements can occur only along active agreements.

In each connected trading component C, set `S_C=sum_{i in C}(B_i-H_i)`. When `S_C >= 0`, we can redistribute payments to realize nonnegative gains to all members, subject to the rules of a permissible clearing arrangement. With baseline status-quo values already deducted, individual rationality is:

`Delta_i >= 0` for every participating operator i.

If `S_C < 0` but a planner seeks the allocation for public benefit, the **minimum transfer-funded subsidy** for that component is `max(0,-S_C)` before transaction/friction costs. An ICR-specific subsidy can be justified separately by `q_git`; it should not automatically be presented as commercially efficient.

### Cooperative Nash bargaining benchmark

For a component C, with a total nonnegative distributable private surplus `S_C+G_C`, bargaining weight `omega_i>0` and disagreement payoff zero, the weighted Nash bargaining solution solves:

`max_{Delta_i>=0} product_{i in C} Delta_i ^ omega_i`, subject to `sum_i Delta_i=S_C+G_C`.

The solution is:

`Delta_i^Nash = (omega_i / sum_{k in C} omega_k)*(S_C+G_C)`.

The simulator uses equal weights as the default. It then calculates the clearing adjustments required to take posted-price outcomes to the target operator payoffs. Importantly, these **clearing adjustments are illustrative multilateral side payments**, not a claim that posted per-unit tariffs by themselves implement the bargaining solution.

For two operators, a bilateral per-unit price p is individually rational in an uncomplicated single-edge case if it is between the guest's per-unit willingness to pay and the host's average incremental cost. A fixed price can fail to exist when congestion or multiple agreements matter. Network-connected multilateral clearing is therefore useful.

## 6. Reporting and interpretation

Report simultaneously:

1. Native coverage (% equal-area grid cells with original coverage).
2. Directed conditional coverage complementarity by home and host.
3. Physical union potential (% of home gaps covered by at least one eligible host).
4. Aggregate initially uncovered roaming demand, actually served demand, and recovery share by time and operator.
5. Residual demand unserved from physical absence, capacity protection or chosen economics.
6. Daily representative operator gain/loss under posted tariff.
7. Cooperative Nash bargaining benchmark and additional transfers.
8. Minimum external subsidy, where social routing is privately loss-making within an eligible trading component.
9. Optional infrastructure alternative and net present value, not yet implemented in v1.

**Avoid a false metric:** Grid area coverage percentages do not equal population coverage, user throughput, traffic served, voice accessibility or probability that a particular UE attaches. Show these as separate outcomes.

## 7. Scenario design and fidelity

### Prototype scenarios

- **Sparse border (40% T1)**: BSNL-style T1 40% native coverage, other TSPs overlapping and complementary; controlled economic comparison.
- **Exact 95/90/2 example**: 2,000 equal-area cells; T1=95%; inside T1's 5% gap, T2 covers 90 cells, T3 covers two separate cells, T4 covers zero; eight remain inaccessible.
- **Peak congestion**: higher utilization and stronger prime-time demand, increasing capacity-denied service.
- **Complementary footprints**: geographically staggered coverage encouraging useful reciprocity.
- **Remote blackspots**: region contains synthetic locations outside every provider's network, so ICR cannot help there.

Numbers are synthetic and can be edited. They are not operator measurements, coverage maps, regulated tariff rates or actual marginal costs.

### Data requirements for production calibration

- Observed signal-quality/RSRP/RSRQ/SINR and independent drive-test coverage by serving technology, mapped to geospatial tiles.
- Site and sector identity, antenna footprints, bands, shared sector/backhaul relationships, capacity and reliability.
- Time-of-day utilization and spare PRBs, active UEs, packet load, VoLTE resources, failures, mobility and coverage handovers.
- Anonymized subscriber counts, border settlements, visitor/seasonal distribution, demand by service and home operator.
- Real wholesale tariff offers, bilateral contract terms, roaming integration costs, multi-operator settlements and fees.
- Site OPEX/CAPEX, energy costs, fiber/satellite backhaul, site-sharing costs and amortization.
- QoS measures tied to applicable TRAI regulations; policies concerning priority and national security in border areas.

### Next mathematical extension

Add binary tower build/upgrade decisions `z_s in {0,1}`, capex `K_s`, discount factor `delta`, and welfare horizon. Solve:

`max_(x,z) sum_t delta^t * [service_private_value + public_value - hosting_cost - operating_cost] - sum_s K_s*z_s`

with tower-to-grid radio service and shared-backhaul constraints, plus counterfactual outcomes: no ICR, bilateral only, full multilateral, peak-only, subsidized ICR and new-build alternatives. Use robust or distributionally robust optimization for uncertain peaks/failures, e.g. capacity satisfaction across high-quantile demand scenarios.

## 9. Known modelling limitations

- Sample geographies and all commercial prices are illustrative and generated, not field-measured.
- Area grids are equal size, not geo-referenced; subscriber shares and demand density are stylized.
- Basic binary coverage does not model RF thresholds, SINR, border radio rules, equipment capability or frequency-band availability.
- Traffic-equivalent units aggregate multiple telecom services; voice/SMS/data priorities are not separated.
- Host capacities are independent per cell. Real neighboring cells often share sites, radio spectrum, sector resources, backhaul and energy limits.
- Time bins are independent; no subscriber state continuity, queueing, stochastic load transitions, reservation guarantees or handover dynamics.
- Reported convex cost uses quadratic formula, while the optimizer uses a four-segment linear approximation.
- Subsidies are **minimum theoretical private-surplus shortfalls**, not an approved government subsidy program.
- Equal-weight bargaining redistributes surplus in a connected transaction network and permits side payments. Its outcome is a benchmark, not an automatically enforceable interconnection contract.
- `No ICR` counterfactual refers to incremental recovery from uncovered subscribers; existing native usage and baseline P&L are deliberately excluded.
- Comparisons are within a representative synthetic day. NPV and build-out economics require longitudinal calibration.

## 10. Validation tests to prioritize

- Directional complementarity: a manually constructed 95/90/2/0 case returns 90%, 2%, 0% conditional coverage and 8% irrecoverable.
- Capacity protection: no simulated admitted roaming load exceeds `max(0,K*(1-r)-L)` in any cell/time.
- Demand feasibility: no guest's served roaming traffic exceeds the original unsatisfied request.
- No self-roaming and no serving a guest whose home network already covers the same cell.
- Budget identity: total posted gains equal total private benefits minus all hosting costs, within floating-point tolerance.
- Cooperative accounting: net side payments across each active component sum to zero; all cooperative gains are nonnegative after the specified minimum subsidy.
- Monotonic sanity checks: setting all foreign coverage to zero produces no ICR; no-ICR policy produces no recovered traffic; increasing reserve cannot increase technical capacity; increasing host utilization cannot increase free capacity if all else is held fixed.
- Relative pricing: changing tariffs must change posted distribution, and must change traffic allocations only in tariff-driven mode.
