Mathematical architecture

The prototype implements a decomposable convex-cost network flow problem with a second, separate financial settlement calculation. In a production model, sector-level radio constraints, handovers and shared backhaul replace the independent-cell approximation.

1. Native geographic coverage

Cᵢ = Σg a(g)·c(g,i) / Σg a(g)
c(g,i) is 1 when operator i covers cell g, otherwise 0.

2. Directed gap complementarity

Mᵢⱼ = Σg a(g)·[1−c(g,i)]·c(g,j) / Σg a(g)·[1−c(g,i)]
The row denominator is the uncovered area of the home operator. Columns are not additive.

3. Safe residual host capacity

S(g,j,t) = max{0, K(g,j,t)·(1−rⱼ) − L(g,j,t)}
Measured site/sector QoS and backhaul constraints must replace this proxy for deployment-grade studies.

4. Roaming flow and constraints

x(g,i,j,t) ≥ 0
Σⱼ x(g,i,j,t) ≤ d(g,i,t)
Σᵢ x(g,i,j,t) ≤ S(g,j,t)
Routing requires missing native coverage, available host coverage and an eligible roaming agreement.

5. Incremental congestion cost

Φ(g,j,t)(y) = cⱼ·y + γⱼ·y²/[2·S(g,j,t)]
Convex cost, optimized with four increasing piecewise-linear marginal cost segments.

6. Commercial or social objective

maxₓ Σgijt wₜ·(bᵢ + q(g,i,t))·x(g,i,j,t) − Σgjt wₜ·Φ(g,j,t)(Σᵢx)
q=0 for private efficiency. q>0 only for the public-interest option.

7. Operator-level posted-price gain

Δᵢ = guest benefitᵢ − host costᵢ + tariff receiptsᵢ − tariff paymentsᵢ
All tariff transfers cancel when summed across operators, before external subsidies.

8. Cooperative settlement

Δᵢᴺ = ωᵢ·(S꜀ + G꜀) / Σk∈C ωₖ
G꜀ = max{0, −S꜀}
Equal bargaining weights in prototype. Each disconnected trading component is cleared separately.

Solution algorithm

For each cell and time window, a minimum-cost flow network links uncovered home-network demand to feasible host resources. Each host has four rising-cost segments. The solver repeatedly augments the cheapest residual path whenever the marginal net benefit is positive, including re-routing through reverse residual edges. This solves the segmented linear program, then recalculates smooth convex costs for financial reporting.

When posted-price admission is selected, guest demand can enter a host only if the guest's incremental value exceeds the wholesale price. Host capacity segments are admitted only when their cost does not exceed that price. The social efficiency mode increases the optimization objective using a separate public-benefit estimate, but never mislabels that public benefit as operator revenue.

What the prototype deliberately does not assume

  • Roaming does not create physical coverage in areas without any operator signal.
  • Multiple host coverage percentages cannot be summed without removing their spatial overlap.
  • Capacity that appears free at noon need not remain free during the evening peak.
  • A socially desirable allocation does not necessarily create a positive profit for every TSP at posted tariffs.
  • An equal-weight Nash clearing arrangement is a settlement benchmark, not a claim that operators will adopt it.
  • The grid-level capacity model is not yet a sector-linked mobile radio-network simulator.
